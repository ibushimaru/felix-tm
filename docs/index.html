Felix TM とは

Felix TM は、翻訳メモリ (TM) と用語集検索を Excel に直接持ち込む アドインです。セル間を移動するたびに、原文を非公開の TM と照合し、 あいまい一致候補を差分ハイライト付きでリアルタイム表示。 承認した訳文はワンクリックで訳文列に書き込まれます。

スプレッドシートで作業する翻訳者のために設計されています — ゲームローカリゼーション、UI 文字列、用語リスト、行単位での翻訳作業全般。

インストール

  1. manifest.xml をダウンロード
  2. Excel でブックを開き、ホーム → アドイン → 詳細設定を表示 → 個人用アドインの管理 → マイ アドインをアップロード から ダウンロードしたファイルを選択
  3. ホームリボン右端の Felix TM ボタンをクリック — シートの横にペインが開きます

上記は Excel on the web の手順です。デスクトップ版は以下。

Windows デスクトップ版
  1. install-windows.bat をダウンロード
  2. ダブルクリックで実行（警告が出た場合は「詳細情報」→「実行」）
  3. Excel を再起動し、ホーム → アドイン → 開発者向けアドイン から Felix TM をクリック

削除は uninstall-windows.bat。 Microsoft 365 または Office 2021 以降。

Mac デスクトップ版
  1. ターミナルを開く（⌘+Space で「ターミナル」を検索）
  2. 次の1行を貼り付けて Enter:
    curl -fsSL https://ibushimaru.github.io/felix-tm/addin/install-mac.sh | sh
  3. Excel を再起動し、挿入 → アドイン → 個人用アドイン から Felix TM を開く

削除:

curl -fsSL https://ibushimaru.github.io/felix-tm/addin/uninstall-mac.sh | sh

初期設定

  1. 設定タブの 原文 A → 訳文 B チップをクリックし、シート上で該当する列のセルをクリックして指定
  2. TM タブの「ブックからインポート」で既存の対訳を取り込み（TMX/TSV ファイルのドロップも可）
  3. 原文セルを選択すると候補が表示されます。カードをクリックで挿入、Set で現在行を TM に登録

主な機能

リアルタイムあいまい一致

レーベンシュタイン距離 + バッグ距離の事前フィルタによる高速検索。セルを選ぶだけで候補を瞬時に表示。元 Felix CAT アルゴリズムの忠実な移植。

差分の可視化

TM との違いを色で表示 — 自動置換された語、要確認の差分、未カバー箇所。何を信用してよく、どこを見るべきかが一目で分かります。

用語集

原文中の登録用語に下線表示、クリックで訳語をコピー。あいまい一致の数値・用語は自動で差し替え（要確認マーク付き）。

コンコーダンス検索

TM 内の部分一致検索（正規表現対応）。「この言い回し、前にどう訳したっけ？」に即答します。

TMX / TSV 入出力

標準フォーマットでのインポート・エクスポート。既存の TM を持ち込み、他ツールとも共有。バックアップにも。

ローカル完結・プライバシー

TM はブラウザの保存領域（IndexedDB）内のみ。サーバーなし、サインイン不要、アナリティクスなし、外部送信なし。

今後の予定: Auto Translate（範囲一括翻訳）と QC チェック — Google Sheets 版で実装済みの機能を順次移植します。

プライバシーの要点

  • TM・用語集はブラウザのローカル保存領域（IndexedDB）に保存されます。Felix TM にサーバーはありません。
  • サインイン不要。公式 Office API を通じて、開いているブックの読み書きのみを行います。
  • アナリティクスなし。トラッキングなし。サードパーティスクリプトなし。
  • ブラウザのサイトデータを消去すると TM も消えます — バックアップには内蔵の TMX/TSV エクスポートをご利用ください。

詳細は プライバシーポリシー をご覧ください。

Google Sheets 版（ベータ）

同じエンジンを Google Sheets に持ち込む Chrome 拡張版もあります。 Auto Translate・QC チェック・検索＆置換まで含むフル機能版ですが、 現在 Google OAuth verification と Chrome Web Store 審査の通過待ちです。 早期アクセスをご希望の方は ibushimaru@veriscio.com までご連絡ください。

Felix CAT との関係

Felix TM は、Ryan Ginstrom 氏が制作し MIT ライセンスでオープンソース公開した Windows 専用翻訳メモリツール Felix CAT から着想を得ており、 マッチングアルゴリズムを共有しています。Felix TM は独立したプロジェクトであり — Excel・Google Sheets と現代の Web 環境を対象に Python と JavaScript で 一から再実装したものです — Ginstrom 氏および元 Felix CAT 製品とは 関係を持ちません。本プロジェクトを可能にしたアルゴリズムへの感謝を申し上げます。

What it is

Felix TM is an add-in that brings translation memory (TM) and glossary lookup directly into Excel. As you move between cells, it matches the source text against your private TM and surfaces fuzzy matches in real time with the differences highlighted. Approved translations are written into the target column with one click.

Built for translators who work in spreadsheets — game localization, UI string tables, terminology lists, anywhere the unit of translation is a row.

Install

  1. Download manifest.xml
  2. In Excel, open a workbook and go to Home → Add-ins → More settings → My Add-ins → Upload My Add-in, then pick the downloaded file
  3. Click the Felix TM button at the right end of the Home ribbon — the pane opens next to your sheet

The steps above are for Excel on the web. For desktop Excel:

Windows desktop
  1. Download install-windows.bat
  2. Double-click it (if a warning appears: "More info" → "Run anyway")
  3. Restart Excel, then open Felix TM from Home → Add-ins → Developer Add-ins

To remove: uninstall-windows.bat. Requires Microsoft 365 or Office 2021+.

Mac desktop
  1. Open Terminal (⌘+Space, type "Terminal")
  2. Paste this one line and press Enter:
    curl -fsSL https://ibushimaru.github.io/felix-tm/addin/install-mac.sh | sh
  3. Restart Excel, then open Felix TM from Insert → Add-ins → My Add-ins

To remove:

curl -fsSL https://ibushimaru.github.io/felix-tm/addin/uninstall-mac.sh | sh

First-time setup

  1. Click the Source A → Target B chips in the Settings tab, then click a cell in the matching column on the sheet
  2. In the TM tab, use "Import from Workbook" to pull in existing translations (or drop a TMX/TSV file)
  3. Select a source cell to see candidates. Click a card to insert; Set registers the current row to the TM

Features

Real-time fuzzy matching

Levenshtein-based scoring with bag-distance pre-filtering. Candidates appear the moment you select a cell. Faithful port of the original Felix CAT algorithm.

Diff visualization

Differences against the TM are colour-coded — auto-substituted words, needs-review diffs, uncovered spans. You see at a glance what to trust and what to check.

Glossary

Registered terms are underlined in the source; click to copy the translation. Numbers and glossary terms in fuzzy matches are substituted automatically, marked for review.

Concordance search

Substring search across the TM, regex supported. Instant answer to "how did I translate this phrase last time?"

TMX / TSV import & export

Standard-format I/O. Bring your existing TM in, share it across tools, and keep backups.

Local-first & private

Your TM lives only in the browser's storage (IndexedDB). No server, no sign-in, no analytics, no external transmission.

Coming next: Auto Translate (batch-fill a range) and QC checks — already implemented in the Google Sheets edition and being ported over.

Privacy at a glance

  • Your TM and glossary live in the browser's local storage (IndexedDB). Felix TM has no server.
  • No sign-in required. The add-in reads and writes only the workbook you have open, through the official Office API.
  • No analytics. No tracking. No third-party scripts.
  • Clearing the browser's site data deletes the TM — use the built-in TMX/TSV export for backups.

About Felix CAT

Felix TM is inspired by and shares its matching algorithm with Felix CAT, the Windows-only translation memory tool originally created by Ryan Ginstrom and released as open source under the MIT license. Felix TM is a separate project — a ground-up re-implementation in Python and JavaScript targeting Excel, Google Sheets and the modern web — and is not affiliated with Mr. Ginstrom or the original Felix CAT product. We are grateful for the algorithm work that made this project possible.
