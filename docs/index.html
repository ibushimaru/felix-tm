Felix TM

Google Sheets と Excel のための翻訳メモリ — ローカル完結、無料、オープンソース。

English

製品概要

Felix TM は、翻訳メモリ (TM) と用語集検索をスプレッドシート上に直接 持ち込むツールです — Google Sheets（Chrome 拡張）と Excel（Office アドイン）の両方に対応。セル間を移動するたびに、原文を非公開の TM と 照合し、あいまい一致候補を差分ハイライト付きでリアルタイム表示。 承認した訳文をワンクリックで訳文列に書き戻します。

スプレッドシート上で作業する翻訳者向けに設計されています — ゲームローカリゼーション、 UI 文字列、用語リスト、行単位での翻訳作業全般。

Excel 版を使う — 無料 Chrome に追加 — Web Store 公開準備中 GitHub でソースを見る

Excel へのインストール

Excel on the web（Microsoft アカウントがあれば無料）と デスクトップ版 Excel で動作します。インストーラーも当方への アカウント登録も不要 — 小さなマニフェストファイルをアップロード するだけで、Excel がこのサイトからペインを読み込みます。

  1. manifest.xml をダウンロード（ブラウザで開いてしまう場合は右クリック→保存）
  2. Excel でブックを開き、ホーム → アドイン → 詳細設定を表示 → 個人用アドインの管理 → マイ アドインをアップロード から ダウンロードしたファイルを選択
  3. ホームリボン右端の Felix TM ボタンをクリック — シートの横にペインが開きます

ペインの設定タブで原文列・訳文列を指定し、Set で行を 登録するか、ブックや TMX/TSV ファイルから既存の翻訳を一括インポート してください。

Excel 版は現在、ライブ検索・挿入・元に戻す・TM/用語集管理・TMX/TSV 入出力に対応しています。Auto Translate と QC（Chrome 拡張版で利用可）は 今後追加予定です。

主な機能

リアルタイムあいまい一致

レーベンシュタイン距離 + バッグ距離の事前フィルタによる高速検索。65 % 以上のマッチを瞬時に表示。元 Felix CAT アルゴリズムの忠実な移植。

Auto Translate

選択範囲に 100 % 一致を一括適用。数字と登録済み用語は自動配置されます。

用語集 & 配置ルール

大文字小文字を保ったまま用語単位で訳語を適用。製品名・バージョン文字列・定型パターン用に正規表現ベースの配置ルールも対応。

品質チェック

数字の不一致、訳出漏れの ALL CAPS 用語、未翻訳の用語集項目を検出。フラグをクリックすればその場で用語登録できます。

TMX / TSV / XLSX 入出力

標準フォーマットでのインポート・エクスポート。既存の TM を取り込んで他ツールと共有できます。

ローカル完結・プライバシー

TM はブラウザの IndexedDB 内に保存。サーバーなし、アナリティクスなし、外部送信なし。Sheets API はブラウザから Google へ直接通信。

プライバシーの要点

  • TM・用語集はブラウザのローカルストレージ（IndexedDB）に保存されます。Felix TM にサーバーはなく、データがあなたの PC を離れることはありません — バックアップには内蔵の TMX/TSV エクスポートをご利用ください。
  • Excel アドインはサインイン不要です。公式 Office API を通じて、開いているブックの読み書きのみを行います。
  • Chrome 拡張の spreadsheets OAuth スコープは、Auto Translate やインポート等の明示的操作時にのみ使用されます。
  • アナリティクスなし。トラッキングなし。サードパーティスクリプトなし。

詳細は プライバシーポリシー をご覧ください。

Felix CAT との関係

Felix TM は、Ryan Ginstrom 氏が制作し MIT ライセンスでオープンソース公開した Windows 専用翻訳メモリツール Felix CAT から着想を得ており、 マッチングアルゴリズムを共有しています。Felix TM は独立したプロジェクトであり — Google Sheets と現代の Web 環境を対象に Python と JavaScript で 一から再実装したものです — Ginstrom 氏および元 Felix CAT 製品とは 関係を持ちません。本プロジェクトを可能にしたアルゴリズムへの感謝を申し上げます。

What it is

Felix TM brings translation memory (TM) and glossary lookup directly into your spreadsheet — Google Sheets (Chrome extension) or Excel (Office add-in). As you move between cells, Felix TM matches the source text against your private TM, surfaces fuzzy matches in real time with the differences highlighted, and writes approved translations back into the target column with one click.

Built for translators who work in spreadsheets — game localization, UI string tables, terminology lists, anywhere the unit of translation is a row.

Get for Excel — free Add to Chrome — coming to the Web Store soon View source on GitHub

Install for Excel

Works in Excel on the web (free with a Microsoft account) and desktop Excel. No installer, no account with us, no server of ours — you upload a small manifest file and Excel loads the pane from this site.

  1. Download manifest.xml (right-click → save if it opens in the browser)
  2. In Excel, open a workbook and go to Home → Add-ins → More settings → My Add-ins → Upload My Add-in, then pick the downloaded file
  3. Click the Felix TM button at the right end of the Home ribbon — the pane opens next to your sheet

Set your source/target columns in the pane's Settings tab, then either register rows with Set or bulk-import existing translations from the workbook or a TMX/TSV file.

The Excel add-in currently covers live search, insert, undo, TM/glossary management and TMX/TSV import/export. Auto Translate and QC (available in the Chrome extension) are coming next.

Features

Real-time fuzzy matching

Levenshtein-based scoring with bag-distance pre-filtering. Finds 65 %+ matches as you type, faithful port of the original Felix CAT algorithm.

Auto Translate

Apply 100 % matches across a selection in one action. Numbers and registered glossary terms are placed automatically.

Glossary & placement rules

Term-level translations with case preservation. Regex-based placement for product names, version strings, and recurring patterns.

Quality control

Catches mismatched numbers, missing ALL CAPS terms, and untranslated glossary items. Click a flag to register the fix.

TMX / TSV / XLSX I/O

Standard format import and export. Bring your existing TM in or share it across tools.

Local-first & private

Your TM lives in your browser's IndexedDB. No backend, no analytics, no external transmission. Sheets API calls go directly browser → Google.

Privacy at a glance

  • Your TM and glossary stay in your browser's local storage (IndexedDB). Felix TM has no server, so your data never leaves your machine — back it up with the built-in TMX/TSV export.
  • The Excel add-in requires no sign-in at all: it reads and writes only the workbook you have open, through the official Office API.
  • The Chrome extension uses the spreadsheets OAuth scope only when you take an explicit action (Auto Translate, Import, etc.).
  • No analytics. No tracking. No third-party scripts.

About Felix CAT

Felix TM is inspired by and shares its matching algorithm with Felix CAT, the Windows-only translation memory tool originally created by Ryan Ginstrom and released as open source under the MIT license. Felix TM is a separate project — a ground-up re-implementation in Python and JavaScript targeting Google Sheets and the modern web — and is not affiliated with Mr. Ginstrom or the original Felix CAT product. We are grateful for the algorithm work that made this project possible.
